# ADR-0003: 대외 전문 통신 방식

- 상태: 확정 (2026-10-01)

## 맥락

카드사와는 TCP 위에서 고정길이 전문을 주고받는다. 응답을 못 받으면 카드사 쪽 결과를 알 수 없으므로, 타임아웃과 망취소가 설계의 핵심이다.

## 대안

- **Netty**: 대외계에서 많이 쓰고 고성능이지만, 학습 범위가 커서 이 프로젝트의 초점(프로토콜, 타임아웃, 망취소)을 흐린다.
- **상시 연결 + 다중화** (연결 몇 개를 유지하며 거래고유번호로 요청·응답을 짝지음): 실제 대외계에 가깝지만, 응답 매칭과 연결 관리가 추가된다.

## 결정

- **`java.net.Socket` + 가상 스레드**. 가상 스레드 덕분에 블로킹 코드로 써도 동시 연결 수가 스레드 수에 묶이지 않는다.
- **거래마다 연결** (v1). 상시 연결은 완성선 이후 개선 과제로 둔다.
- 길이 4바이트 접두 프레이밍. 정확히 그 길이만큼 읽을 때까지 반복해서 읽는다 (TCP는 메시지 경계를 보장하지 않는다).
- 타임아웃, 재시도, 망취소 규칙은 [02-message-spec.md](../02-message-spec.md) 1장을 따른다.
- 전문은 송신 전·수신 후 `message_log`에 기록하되 **카드번호는 마스킹**한다.

## 결과

- 구조가 단순해서 망취소와 타임아웃 테스트에 집중할 수 있다.
- 거래마다 TCP 연결 비용(핸드셰이크)이 든다. 측정 대상에 포함한다.
